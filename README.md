# Squad Admin Panel

Веб-панель администратора для игрового сервера **Squad**, управляющая им по
протоколу **RCON**. Показывает игроков и отряды онлайн, состояние сервера,
живой чат-лог, и позволяет выполнять все админ-команды (кик, бан, варн, смена
команды, смена карты, управление матчем, настройки сервера) прямо из браузера.

Написана на чистом **Node.js без единой внешней зависимости** — не нужно
`npm install`, достаточно установленного Node.js 16+.

---

## Возможности

- **Dashboard** — онлайн/лимит игроков, текущая и следующая карта, стороны, название сервера, быстрые действия.
- **Игроки** — таблица всех игроков (ID, имя, команда, отряд, роль, SteamID/EOS). По каждому: Warn, Kick, Ban (с выбором срока и причины), смена команды, удаление из отряда, снятие командира. Поиск/фильтр.
- **Отряды** — список отрядов по командам, роспуск отряда одной кнопкой.
- **Карты / Матч** — смена карты сейчас, установка следующей карты (выпадающий список популярных слоёв + свободный ввод), рестарт/завершение матча, пауза/снятие паузы.
- **Сообщения** — Broadcast всем игрокам и сообщение в админ-чат.
- **Настройки** — лимит игроков, пароль сервера, лимит публичной очереди, slomo (скорость игры), claim техники и др.
- **Логи** — живой поток чата, админ-действий и системных событий (через WebSocket) с фильтрами.
- **Баны** — список банов, выданных через панель в текущей сессии.
- **Консоль** — отправка любой RCON-команды напрямую и просмотр ответа сервера.

## Требования

1. **Node.js 16+** — https://nodejs.org (проверить: `node -v`).
2. **Включённый RCON на сервере Squad.** В файле
   `SquadGame/ServerConfig/Rcon.cfg` задайте пароль и порт:
   ```
   Password=ВАШ_ПАРОЛЬ_RCON
   Port=21114
   ```
   Убедитесь, что RCON-порт (по умолчанию 21114/TCP) открыт и доступен с той
   машины, где запускается панель.

---

## Установка и запуск

1. Откройте папку `squad-admin-panel` в терминале.
2. Отредактируйте **`config.json`** — впишите адрес, порт и пароль вашего RCON:
   ```json
   {
     "rconHost": "IP_ВАШЕГО_СЕРВЕРА",
     "rconPort": 21114,
     "rconPassword": "ВАШ_ПАРОЛЬ_RCON",
     "webHost": "127.0.0.1",
     "webPort": 3000,
     "panelUser": "",
     "panelPassword": ""
   }
   ```
3. Запустите:
   ```
   node server.js
   ```
   (или `npm start`)
4. Откройте в браузере **http://127.0.0.1:3000**

Если панель и сервер Squad на одной машине — оставьте `rconHost` = `127.0.0.1`.

## Настройки конфигурации (`config.json`)

| Поле            | Описание                                                                 |
|-----------------|--------------------------------------------------------------------------|
| `rconHost`      | IP/хост сервера Squad, где включён RCON                                   |
| `rconPort`      | Порт RCON (по умолчанию `21114`)                                         |
| `rconPassword`  | Пароль RCON из `Rcon.cfg`                                                 |
| `webHost`       | Интерфейс, на котором слушает панель (`127.0.0.1` = только локально)      |
| `webPort`       | Порт веб-панели                                                          |
| `panelUser`     | (опц.) логин для входа в панель (HTTP Basic). Пусто = без авторизации     |
| `panelPassword` | (опц.) пароль для входа в панель                                         |

Значения можно задать и через переменные окружения:
`SQUAD_RCON_HOST`, `SQUAD_RCON_PORT`, `SQUAD_RCON_PASSWORD`,
`PANEL_HOST`, `PANEL_PORT`, `PANEL_USER`, `PANEL_PASSWORD`.

---

## Безопасность

- По умолчанию панель слушает только `127.0.0.1` — доступна лишь с этой машины.
- Чтобы открыть доступ по сети, поставьте `webHost` = `0.0.0.0` **и обязательно**
  задайте `panelUser`/`panelPassword`. Ещё лучше — держать панель за обратным
  прокси (nginx) с HTTPS.
- Никогда не публикуйте панель в интернет без авторизации: она даёт полный
  контроль над сервером.

## Как это устроено

```
squad-admin-panel/
├── server.js        # HTTP + WebSocket сервер, REST API, раздача статики
├── rcon.js          # Клиент Source RCON для Squad + парсеры ответов
├── config.json      # ваши настройки (адрес/пароль RCON, порт панели)
├── package.json
└── public/
    ├── index.html   # интерфейс
    ├── style.css     # оформление (тёмная тема)
    └── app.js        # логика панели (vanilla JS)
```

Панель общается с сервером по **Valve Source RCON** (TCP) со специфичными для
Squad деталями: асинхронные чат-пакеты (тип 1) и разбиение длинных ответов
(например `ListPlayers`) на несколько пакетов — всё это обрабатывается в
`rcon.js`.

REST API: `/api/status`, `/api/players`, `/api/squads`, `/api/log`,
`/api/bans`, `POST /api/command`. Живые события идут через WebSocket на `/ws`.

## Справочник RCON-команд Squad

| Команда | Назначение |
|---------|-----------|
| `AdminKick / AdminKickById <id> <причина>` | Кик игрока |
| `AdminBan / AdminBanById <id> <срок> <причина>` | Бан (0=перм, 1d, 1M …) |
| `AdminWarn / AdminWarnById <id> <текст>` | Предупреждение |
| `AdminForceTeamChangeById <id>` | Сменить команду игроку |
| `AdminRemovePlayerFromSquadById <id>` | Удалить из отряда |
| `AdminDemoteCommanderById <id>` | Снять командира |
| `AdminDisbandSquad <team> <squad>` | Распустить отряд |
| `AdminChangeLayer <layer>` | Сменить карту немедленно |
| `AdminSetNextLayer <layer>` | Установить следующую карту |
| `AdminRestartMatch / AdminEndMatch` | Рестарт / завершение матча |
| `AdminPauseMatch / AdminUnpauseMatch` | Пауза матча |
| `AdminBroadcast <текст>` | Сообщение всем игрокам |
| `AdminSetMaxNumPlayers <n>` | Лимит игроков |
| `AdminSetServerPassword <pass>` | Пароль сервера (""=снять) |
| `AdminSetPublicQueueLimit <n>` | Лимит очереди |
| `AdminSlomo <множитель>` | Скорость игры |
| `ListPlayers / ListSquads / ShowServerInfo / ShowNextMap` | Информационные |

Полный список: https://squad.fandom.com/wiki/Server_Administration

## Устранение неполадок

- **«RCON отключён» в панели** — проверьте `rconHost`/`rconPort`/`rconPassword`,
  что RCON включён в `Rcon.cfg` и порт открыт в фаерволе. Ошибки видны в
  терминале, где запущен `node server.js`.
- **`ECONNREFUSED`** — сервер Squad не слушает RCON по указанному адресу/порту.
- **Списки пустые, но статус «подключён»** — возможно, сервер пустой, либо
  формат вывода отличается: откройте вкладку «Консоль» и выполните `ListPlayers`
  вручную, чтобы увидеть сырой ответ.

## Плагины (автоматизация)

Вкладка **Плагины** в панели добавляет автоматизацию поверх RCON (идеи портированы из [RNSquadJS](https://github.com/lACTEPUKCl/RNSquadJS), события — из [squad-rcon](https://github.com/iamalone98/squad-rcon)). Каждый плагин включается тумблером и настраивается прямо в UI; настройки сохраняются в `plugins.json`. Плагины работают, пока панель запущена и RCON подключён.

| Плагин | Что делает | Ключевые настройки |
|--------|-----------|--------------------|
| **broadcast** | Периодически шлёт сообщения в чат (по кругу) | интервал, список сообщений, «только когда есть игроки» |
| **chatCommands** | Реагирует на команды в чате: `!report`, `!admins`, `!help` и свои пары `!cmd = ответ` | вкл. `!report`, карта команд |
| **skipmapVote** | Голосование за пропуск карты (`!skipmap` → игроки пишут `+`) | команда, символ голоса, длительность, нужно голосов, кулдаун |
| **autoKickUnassigned** | Предупреждает и кикает игроков вне отряда после льготного периода | мин. игроков, льгота, период проверки, тексты |
| **warnOnSquadCreate** | Напоминает создателю отряда про роль SL | текст сообщения |
| **adminCamAlert** | Оповещает админ-чат о входе в админ-камеру | вкл. оповещение |

Важно: эти плагины используют только RCON-события (чат, создание отряда, админ-камера) и опрос `ListPlayers`. Плагины из RNSquadJS, которым нужен разбор лог-файла сервера (`SquadGame.log`) — статистика киллов/тимкиллов, ELO-рейтинг, FOB-урон и т.п. — требуют прямого доступа к файлам сервера (локально или по SFTP) и здесь не реализованы. Их можно добавить отдельно, если дать панели доступ к `SquadGame.log` (см. третий референс — [squad-logs](https://github.com/lACTEPUKCl/squad-logs)).

```

├── server.js       # HTTP + WebSocket + REST + интеграция плагинов

```
